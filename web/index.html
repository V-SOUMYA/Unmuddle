How it works

  1. Your group joins with the code and answers in their own words.
  2. An AI checks each answer against the lesson's reference answer.
  3. Sentence embeddings group the wrong answers that share an idea.
  4. An LLM names each misconception and writes a quick fix for you.
  5. Each learner gets kind feedback and one follow-up question. When they get it right, their dot turns teal on your screen.
